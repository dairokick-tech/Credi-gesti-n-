# CREDI GESTIÓN — versión sin credenciales

Esta versión no usa Supabase ni requiere correo, contraseña, URL de proyecto o API key.

- Los datos se guardan en `localStorage` del navegador.
- No hay pantalla de inicio de sesión.
- Incluye clientes, créditos, cronogramas, pagos, caja, reportes y CSV.
- Puedes descargar/restaurar un respaldo JSON desde el menú lateral.

## Importante
Los datos quedan guardados en el dispositivo/navegador donde uses la aplicación. Si borras los datos del navegador o cambias de dispositivo, necesitas un respaldo para recuperarlos.

Abre `index.html` con un servidor estático (por ejemplo, VS Code Live Server) para usarla.
